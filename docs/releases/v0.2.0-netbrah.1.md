# speedread 0.2.0-netbrah.1 — fork pre-release for Claude Desktop

A pre-release of the [netbrah fork](https://github.com/netbrah/speedread/blob/v0.2.0-netbrah.1/docs/FORK.md) of [speedread](https://github.com/brennengreen/speedread) by Brennen Green, based on upstream `37abea2` (0.1.0 plus Luau support). It is not an upstream release.

> **Not yet run on macOS.** This binary was cross-compiled for Apple Silicon on Linux. It compiles and lints clean for `aarch64-apple-darwin`, and the same source passes its 97 tests on Linux, but nobody has executed this build on a Mac. Treat the first install as the test. Remove it from Claude Desktop under Settings → Extensions if it misbehaves.

## What the fork adds

- **A request cannot run away.** Every request has a deadline (10 s, walking and parsing together) and a file limit, and an MCP cancellation stops the work. An answer cut short ends with `incomplete: …` instead of claiming something is absent.
- **A long-lived server stays small.** Cached contents and outlines are bounded by bytes (`--cache-mb`, 256 MiB), lines longer than 4 MiB are not buffered, and memory a request freed is returned when it ends. After a session on Chromium (474,447 files) the server holds 125 MiB against upstream's 222 MiB; after searching a 200 MiB one-line file, 20–23 MiB against about 1 GiB.
- **No assumed working directory.** `base_dir` on every tool, `--no-cwd-root`, and lookups that run in the root containing the target.
- **Faster traces on large trees.** One walk per level instead of three: `trace` on Chromium takes 4.7–5.8 s against 7.8–10.7 s.
- **Structural search** (`search` with `ast=true`): code with holes matched against syntax, opt-in.
- **Ancestor context** (`output=scopes`): the loop and branch headers between a symbol and a hit, opt-in.
- **`trace` relationship kinds:** call sites inside closures (`λ`) and places a function is passed, assigned or returned (`→`).

Measurements, method and known costs: [docs/specs/eval.md](https://github.com/netbrah/speedread/blob/v0.2.0-netbrah.1/docs/specs/eval.md).

## Install in Claude Desktop

Download `speedread-aarch64-apple-darwin.mcpb` below and open it. Claude Desktop asks which folder speedread may read; reads outside it are refused. It installs as **speedread (netbrah fork)**, beside upstream's bundle rather than over it. Both offer tools named `map`, `read`, `search` and `trace`, so enable one at a time.

Requires macOS 11 or later on Apple Silicon. The binary is ad-hoc signed, not notarized. If macOS refuses to run it after a browser download, clear the quarantine flag on the downloaded file first: `xattr -d com.apple.quarantine speedread-aarch64-apple-darwin.mcpb`.

## Command line

```sh
mkdir -p ~/.local/bin
curl -fsSL https://github.com/netbrah/speedread/releases/download/v0.2.0-netbrah.1/speedread-aarch64-apple-darwin.tar.gz | tar -xz -C ~/.local/bin
speedread --version   # speedread 0.2.0-netbrah.1
```

## Known limits

- Never executed on macOS, as above; the macOS fast directory walker in particular has only been compiled.
- Content after a line longer than 4 MiB is not text-searched; the answer names the files.
- A working set larger than `--cache-mb` is re-parsed on access.
- A depth-2 trace on a Chromium-sized tree, or any whole-tree request on a cold disk cache, can hit the 10 s deadline and return a partial answer with a note. `--deadline-ms 30000` waits longer.
- Not listed in the MCP Registry.
