# speedread 0.2.1-netbrah.1 — full release of the netbrah fork

A full release of the [netbrah fork](https://github.com/netbrah/speedread/blob/v0.2.1-netbrah.1/docs/FORK.md) of [https://github.com/brennengreen/speedread](https://github.com/brennengreen/speedread) by Brennen Green. The MIT license is preserved. It is not an upstream release.

GitHub Actions credits were exhausted, so this tag was compiled on Linux with `scripts/fork-release.sh` (cargo-zigbuild) and uploaded by hand. The release is not a pre-release, so GitHub marks it latest.

## What changed since 0.2.0-netbrah.3

- Docs and crate metadata present this repository as netbrah's fork of speedread by Brennen Green.
- The MCP registry workflow, Homebrew formula, and release job publish this fork (`io.github.netbrah/speedread`, `netbrah/speedread`). Upstream's registry name `io.github.brennengreen/speedread` and the upstream docs site are unchanged.
- The Pages workflow no longer deploys or IndexNow-pings https://brennengreen.github.io/speedread/.
- Reading, searching, tracing, and mapping are unchanged from 0.2.0-netbrah.3. `--unrestricted` is unchanged.

## Install

| Host | How |
|---|---|
| Claude Code | `claude plugin marketplace add netbrah/speedread#v0.2.1-netbrah.1` then `claude plugin install speedread-netbrah@netbrah-speedread` |
| Claude Cowork | Customize > Plugins > upload `speedread-netbrah-plugin.zip` |
| Claude Desktop chat | open `speedread-aarch64-apple-darwin.mcpb` (Apple Silicon) |
| Cursor | copy `plugins/speedread-netbrah` into `~/.cursor/plugins/local/` and reload |
| Grok Build | `grok plugin install netbrah/speedread@v0.2.1-netbrah.1#plugins/speedread-netbrah --trust` |
| Perplexity Computer | Plugins > Add custom > Import plugin from GitHub > `https://github.com/netbrah/speedread/tree/v0.2.1-netbrah.1/plugins/speedread-netbrah` |

It installs as **speedread (netbrah fork)**, beside upstream's rather than over it.

## Command line

```sh
mkdir -p ~/.local/bin
curl -fsSL https://github.com/netbrah/speedread/releases/download/v0.2.1-netbrah.1/speedread-aarch64-apple-darwin.tar.gz | tar -xz -C ~/.local/bin
speedread --version   # speedread 0.2.1-netbrah.1
```

Replace `aarch64-apple-darwin` with `x86_64-apple-darwin`, `x86_64-unknown-linux-musl`, or `aarch64-unknown-linux-musl`. Checksums are in `sha256.txt` on this release.

## Known limits

- The macOS binaries are cross-compiled on Linux and have not been executed on a Mac.
- The Linux arm64 binary is cross-compiled. The x86_64 Linux binary is the one run before upload.
- Registry publish (`io.github.netbrah/speedread`) did not run, because it is a GitHub Actions job and Actions credits are exhausted.
